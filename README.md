# C-RAM Simulator

Take control of a truck mounted C-RAM turret and defend your truck full of soldiers against attacking helicopters and jets.

## Getting Started

### Starting the Game

**Requires:** Python 3.9 - 3.14
1. Install the required libraries, preferably in a venv.

    ```
    pip install -r requirements.txt
    ```
2. Run the program.

    ```
    python C_RAM_simulator.py
    ```

### Controls

* **`Left Arrow`/`Right Arrow`** rotate turret  
* **`Up Arrow`** fire turret
