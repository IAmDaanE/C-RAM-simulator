# C-RAM-simulator

Control a truck mounted C-RAM turret and defend your truck full of soldiers from attacking helicopters and jets.

## Getting Started

### Getting the Source

This project is [hosted on GitHub](https://github.com/IAmDaanE/C-RAM-simulator). You can download the zip or clone this project directly using this command:

```
git clone git@github.com:IAmDaanE/C-RAM-simulator.git
```

### Running the Program

requires: python 3.11 or higher
1.Install the required libraries.
```bash
pip install -r requirements.txt
```

2.Run the game
```bash
//inside the project directory
python C-RAM_simulator.py
```

### Controls

* **`Left Arrow`/`Right Arrow`** rotate turret  
* **`Up Arrow`** fire turret
